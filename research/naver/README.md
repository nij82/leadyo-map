# 네이버 목록 대조·등록 작업

로컬 관리자 화면 `/admin?tab=projects`의 **네이버 목록 대조·등록**에서 한 번 시작한다.

1. 공개 분양 화면의 실제 지역 선택 응답으로 경기도 시군구·읍면동을 순회한다.
2. 아파트 목록 식별자를 중복 제거하고, 한 요청에서 상세 최대 20개를 읽는다. 빈 지역을 읽는 요청도 최대 5회로 제한한다. 개별 공개 요청은 2초, 처리 묶음은 30초 간격이다.
3. 민간임대 등은 범위 밖으로 기록한다. 입주예정월이 경과했거나 공급 단계·주소가 불확실하면 보류한다. 입주예정은 미분양 또는 실제 판매 중이라는 증거가 아니다.
4. 기존 현장은 이름·사업지·200m 이내 좌표를 함께 대조한다. 띄어쓰기와 같은 지번의 부가 설명은 허용하되, 다른 차수·블록은 합치지 않는다.
5. 신규 현장은 네이버 목록·상세의 식별자와 동일명, 지역에 맞는 사업지, 좌표 범위, 입주예정월·공급 단계가 확인된 경우 자동 등록한다. 청약홈의 동일명·사업지·공고 링크는 추가 근거로 남긴다. 이름 변경이나 별칭을 추측해서 기존 현장과 합치지 않는다.
6. 실제 DB 저장은 로그인된 관리자의 서버 클라이언트로 수행한다. RLS·감사 트리거를 유지하며 서비스 키나 SQL 도구로 인증을 우회하지 않는다.

## 진행 기록

- `comparison-progress.json`: 지역 위치, 상세 대기열, 출처 링크, 검증 근거, 제외/보류, 수집 오류.
- `comparison-registration-progress.json`: 등록 커서, 등록/기존/보류 개수, 저장 오류.
- `registration-progress.json`: 이전 8개 검증 자료의 완료 기록. 새 작업과 분리하여 보존한다.

관리자 화면을 열어 둔 동안 다음 묶음이 이어진다. 화면을 닫아도 저장한 커서는 남으며, 진행 중인 작업은 관리자 화면 재진입 시 재개한다. 접근 제한·네트워크·DB 오류는 자동 반복하지 않고 중단한다. 원인을 해결한 뒤 같은 시작 버튼으로 이어간다. 중간 저장 실패 후 다시 실행해도 기존 현장을 대조하여 중복 등록을 방지한다.

현재 기능은 **개발 서버 전용, 경기도 아파트 한 작업**이다. 전국 전체 목록이나 정기 동기화 완료를 의미하지 않는다. Python 3, requests, BeautifulSoup가 설치된 로컬 환경을 사용한다. 공개 응답을 읽을 수 있다는 사실이 대량 수집·상업적 재사용 권한을 보장하지는 않는다. 차단·접근 제한을 우회하지 않는다.
