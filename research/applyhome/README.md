# 청약홈 APT 분양정보 수집 자료

- 원본: [한국부동산원 청약홈 APT 분양정보](https://www.data.go.kr/data/15101046/fileData.do), 2025-11-28 공개 CSV
- 수집일: 2026-09-29
- 이용허락범위: 공공데이터포털 표기 `제한 없음`
- 원본 2,594건(2020–2025 공고), 2025년 공고 290건을 검토 후보로 분리
- 실행: `python3 research/applyhome/prepare_apt.py`

`apt_2025_candidates.json`은 **운영 현장이나 현재 모집공고가 아니다**. 원본에 위·경도가 없으며, 공급위치가 지번·블록·일원 등으로 적힌 경우 정확한 사업지 좌표 검증이 필요하다. 2026년 신규 공고는 이 연간 파일에 없다. 최신 청약홈 분양정보 API 승인키가 있어야 이어받을 수 있다.

이 자료는 구인공고를 생성하거나 다른 사이트의 연락처를 복사하지 않는다. 현장 DB로 게시하기 전에 공고 중복/현장 동일성, 사업지 주소, 위치 좌표, 현재성, 상품 유형을 검수한다. 기존 관리자 현장 및 모집공고는 덮어쓰지 않는다.

## 최신 API 수집

공공데이터포털의 [청약홈 분양정보 조회 서비스](https://www.data.go.kr/data/15098547/openapi.do) 활용신청 후 `service/.env.local`에 `APPLYHOME_SERVICE_KEY=...`를 추가한다. `python3 research/applyhome/fetch_current.py`를 실행하면 공고일 2025-01-01 이후 아파트·오피스텔·무순위·임의공급 원본과 검토 후보를 날짜별 JSON으로 생성한다. 인증키는 파일/로그에 저장하지 않는다. 수집 결과 역시 주소 좌표와 현재성 검증 전에는 서비스 DB에 게시하지 않는다.

### 2026-09-29 기본 분양 유형 집계

- API 원본: APT 579건, 오피스텔 등 167건 (`2025-01-01` 이후 공고)
- 분양 검토 후보: `분양전환 가능임대` 4건을 제외한 아파트 575건, `오피스텔`로 명시된 132건, 총 707건
- 일반 분양 후보 공고연도: 2025년 389건, 2026년 318건. 최신 공고일은 2026-09-23.
- 일반 분양 후보 중 같은 이름·주소 조합의 중복 기록은 57건이다. 반복 공고 또는 복합 상품 여부 확인 전에는 자동으로 합치지 않는다.
- 최종 결과 파일: `applyhome_raw_2026-09-29.json`, `applyhome_candidates_2026-09-29.json` (아래 확장 유형을 포함한 로컬 검토 전용)
- `requests` 파이썬 패키지가 필요하다. 개발 PC에서 수집 실행과 정규화 검증을 마쳤다.

### 무순위·임의공급 확장 확인

2026-09-29에 같은 청약홈 API의 APT 무순위·잔여세대 및 임의공급 조회를 추가했다. `2025-01-01` 이후 공고는 무순위 505건, 불법행위 재공급 93건, 임의공급 505건이다. API 원본은 총 1,814건이며, 분양전환 가능임대 4건을 제외한 검토 후보는 **공고 기록 1,810건**이다. 이는 새 현장 수나 현재 미분양 현장 수가 아니다. 불법행위 재공급 93건은 미분양 후보와 분리한다. 실제 미분양 잔여 물량은 기준일이 있는 별도 단지별 자료나 현장 확인이 있어야만 표시한다.

### 현장 등록 검토

`prepare_project_review.py`는 1,810개 분양 공고를 사업지 주소·상품 유형별 1,020개 묶음으로 정리한다. `geocode_project_review.py`와 `geocode_fallback.py`는 네이버 Geocoding 결과를 로컬 파일에 저장한다. 원문에 명시된 지번·도로명주소가 지오코딩 결과와 일치하고 명칭이 하나이며 다른 후보와 좌표·현장명이 겹치지 않는 544개 묶음은 `prepare_import_preview.py`가 `project_import_preview_2026-09-29.json`으로 분리했다. 나머지 476개 묶음은 `project_import_hold_2026-09-29.json`에 사유와 함께 보류했다. 검토 목록에는 이미 DB에 있는 현장이 포함될 수 있으므로 실제 등록 전 중복 대조가 필요하다. 이 단계에서 DB 등록이나 게시를 하지 않았다.

### 공고·주택형 상세 수집

`python3 research/applyhome/fetch_models.py`는 청약홈의 APT·오피스텔·무순위·임의공급 주택형별 상세조회 4종을 `applyhome_models_날짜.json`으로 수집한다. `python3 research/applyhome/prepare_project_details.py`는 기존 공고 원본과 연결해 다음 로컬 검토 자료를 생성한다.

- `notice_details_날짜.json`: 아파트·오피스텔 분양 공고별 사업주체, 시공사(제공된 경우), 공고·청약·계약 일정, 공고 공급세대수, 입주예정월, 주택형별 공급세대수와 최고 공급금액. 사업주체를 법적 시행사로 단정하지 않는다.
- `project_details_review_날짜.json`: 이미 검증된 지도 현장과 공고를 연결한 자료. 반경 3km의 다른 검증 현장 중 입주예정월이 남은 곳도 **직선거리 기반 참고 목록**으로 넣는다. 청약홈 수집 범위 밖 단지는 포함하지 않는다.
- `project_details_summary_날짜.csv`, `project_details_report_날짜.json`: 현장별 검토표와 연결·누락 집계.

공고의 공급세대수와 주택형별 세대수 합계는 원본에서도 다를 수 있으므로 별도 필드로 유지한다. 공급금액은 주택형별 **분양최고금액(만원)**이며 현재 판매가가 아니다. 원본 JSON은 원문 필드를 그대로 보존한다. 이 스크립트들은 운영 DB에 쓰지 않는다.

## 공고 연도 제한 없는 현재성 후보 수집 (2026-09-30)

실행: `python3 -B research/applyhome/fetch_active_projects.py`

기존 `fetch_current.py`의 2025년 이후 조회는 그대로 유지하고, 새 수집기는 같은 4개 API를 공고일 하한 없이 전 페이지 조회한다. API가 제공하는 기간까지 수집하는 것이며, 청약홈에 없는 현장까지 포함한다고 보장하지 않는다. 아파트·오피스텔 공급유형 필터는 기존 기준을 유지한다.

- 기준일이 포함된 월 이후의 입주예정월, 또는 기준일 이후 청약·계약 일정이 있는 공고는 위치·동일성 검토 후보로 분리한다. 현재 월 입주예정도 포함한다.
- 입주예정은 원본 공고 기준이며 실제 입주 여부나 잔여 물량을 증명하지 않는다. 모든 후보의 현재 분양 상태는 `unverified`로 유지한다.
- 입주·청약·계약 일정이 지났거나 없으면 `needs_current_sale_verification` 목록에 보존한다. 분양 종료로 단정하거나 자동 게시하지 않는다. 이 중 아직 판매 중인 현장은 별도 최신 근거가 필요하다.
- 공고 날짜가 잘못됐거나 기준일 이후이면 공고 날짜 검증 대상으로 분리한다.
- `--as-of YYYY-MM-DD`로 판정 기준일, `--baseline 파일경로`로 이전 수집 목록을 지정할 수 있다. `--raw-file 파일경로`로 저장된 전체기간 원본을 재분류할 수 있다.
- 출력은 `full_history_raw`, `active_candidates`, `active_additional_review`, `active_new_address_review`, `current_sale_verification`, `active_collection_report` 파일로 분리한다. 기존 원본·검토·등록 파일을 덮어쓰지 않는다.
- 주소·공급유형 묶음은 검토 단위이며, 주소 표기 차이·동일 사업지의 블록 차이 때문에 실제 고유 현장 수와 다를 수 있다. 기존 DB의 현장과 대조하기 전에는 신규 등록 건수로 해석하지 않는다.
- 회귀 검증: `python3 -B -m unittest discover -s research/applyhome -p test_active_collection.py`

실제 조회 원본은 5,870건(APT 2,884, 오피스텔 등 621, 무순위 1,700, 임의공급 665). 공급유형 필터 이후 현재성 후보는 공고 1,596건, 주소·유형 검토 묶음 890개다. 이전 수집에 없던 2022~2024년 공고 403건은 모두 입주예정월 근거로 포함됐다. 추가 공고를 묶으면 327개이며, 기존 수집 주소와 겹치는 72개를 제외한 새 주소·유형 묶음은 255개다. 이는 운영 DB 등록 결과가 아니다.
