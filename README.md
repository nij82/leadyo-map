# Leadyo Map 데모

분양 현장과 구인정보를 역할별로 체험하는 단일 HTML 프로토타입(v0.17)입니다.

모바일에서 현장을 선택하면 지도 대신 상세 화면이 전체 화면으로 열립니다. 현장명과 `지도` 버튼만 상단에 남고, 요약 정보와 본문은 함께 스크롤됩니다.

모바일 지도에는 현장 목록을 겹쳐 표시하지 않습니다. 지도 핀을 터치하면 현장 상세가 전체 화면으로 열리고, 상단의 `지도` 버튼으로 돌아갈 수 있습니다. 데스크톱 현장 목록은 유지됩니다.

분양상담사 화면의 구인정보에는 두 번째 공고 뒤에 리드요 서비스 안내 카드가 표시됩니다. 카드는 리드요 공식 홈페이지로 연결됩니다.

- **분양상담사:** 지도에서 현장·구인정보 확인, 1:1 문의, 답변 확인, 전화문의
- **모집공고자:** 상담사 기능과 자기 공고 등록·수정, 받은 문의 답변
- **운영관리자:** 전체 공고 관리·승인, 현장정보 수정

## 실행

`index.html`을 브라우저에서 열고 첫 화면에서 역할을 선택하세요. 화면 상단에서 언제든 역할을 바꿀 수 있습니다. 별도 설치나 서버가 필요하지 않습니다.

현장·조직·금액·연락처·지도 위치는 모두 가상입니다. 문의·답변·수정 내용은 사용 중인 브라우저의 로컬 저장소에만 남습니다. 실제 문의 전송이나 전화 연결, 로그인·서버 권한 검증은 구현되지 않았습니다.
