# Leadyo Map 데모 v0.26

아파트 분양 현장과 구인정보를 찾고, 같은 계정·공고·문의 데이터로 모집 및 운영 흐름을 체험하는 단일 HTML 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 엽니다. 첫 화면에서 분양상담사·모집공고자·운영관리자 체험 계정을 선택하거나 이메일 가입을 체험합니다. 상단 전환 버튼으로 언제든 계정을 바꿀 수 있습니다.

- **분양상담사:** 현장 찾기, 내 문의. 공고에 문의를 남기고 답변과 문의 당시 조건을 확인합니다.
- **모집공고자:** 현장 찾기, 내 공고, 문의함(받은 문의·보낸 문의). 기본 회원이 같은 계정으로 추가 가입하며 승인 없이 바로 공고를 게시합니다.
- **운영관리자:** 현장 찾기, 모집공고 관리, 현장정보 관리, 회원 관리. 신고 접수와 운영 기록은 공고 관리 안에서 확인합니다.

## 반영한 정책

- 기본 가입과 로그인은 이메일 인증 체험입니다. 인증번호는 화면에 표시하고 5분 동안 유효합니다.
- 모집공고자 추가 가입은 별도 계정을 만들지 않으며 운영자 승인이 필요하지 않습니다.
- 공고 등록은 즉시 공개됩니다. 개인(팀원)·팀장·본부장·팀 전체 RT를 입력하고 팀장+팀원 합계를 표시합니다.
- 전화번호 공개 동의를 공고별로 받습니다. 비공개 번호는 전화문의 화면에 표시하지 않습니다.
- 운영자는 공고를 숨김·게시·삭제할 수 있으며 처리 사유가 기록됩니다. 삭제 공고는 숨김 상태로 복구할 수 있습니다.
- 작성자가 공고를 수정해도 운영자가 숨긴 상태가 유지됩니다. 작성자는 자신의 게시 중 공고를 종료하고 종료 공고를 재게시할 수 있습니다.
- 회원 정지는 공고 등록·문의·답변을 제한하고 해당 회원의 공개 공고를 숨깁니다. 정지 해제 시 자동으로 재게시하지 않습니다.
- 문의와 답변은 공고 소유 계정에 연결됩니다. 공고 수정·삭제 후에도 문의 당시 조건과 기존 대화가 남습니다. 삭제된 공고에는 추가 답변을 받지 않습니다.
- 수집 자료 현장과 가상 현장을 같은 지도·관리 데이터에 연결했습니다. 현장정보 수정은 지도와 상세에 반영됩니다.

## 지도와 데모 데이터

외부 공개자료에서 선별한 아파트 분양 샘플 17건(현장 16곳)과 가상 체험 공고 16건(현장 8곳)을 함께 사용합니다. 기본 상태에서 가상 공고 1건은 모집 종료 상태입니다. 수집 샘플은 실제 회원 소유 공고가 아니며 현재 모집 여부는 확인되지 않았습니다. 회원 계정이나 전화번호가 없어 문의 연결 불가 안내를 표시합니다. 원문 링크는 사용자 화면에 표시하지 않고 수집 기록은 내부 `research/`에 보관합니다.

확인되지 않은 현장 상품정보는 `미확인`으로 표시합니다. 오피스텔·숙박시설·상가·민간임대는 지도에서 제외합니다. 지도 핀은 정확한 건물 좌표가 아닌 지역 단위 예시 위치입니다.

- 현장 상세는 `구인정보`·`현장 상세` 두 탭입니다.
- 모바일 전체 지도에 하단 현장 목록을 겹쳐 표시하지 않습니다.
- 현장 선택 시 모바일 전체 화면에 상세를 표시합니다. 현장명·지도 복귀 버튼만 고정하고 요약과 본문은 스크롤합니다.
- 군집 선택 시 모달 없이 지도를 확대합니다.
- 공고의 `1:1 문의`·`전화문의` 버튼은 5:5 너비입니다. 같은 직급의 공고 조건 비교도 제공합니다.
- 분양상담사 화면의 리드요 서비스 안내 카드는 유지합니다.

## 저장 및 구현 범위

데이터는 이 브라우저의 `localStorage` 키 `leadyo-prototype-v026`에 저장합니다. 이전 버전의 저장 키는 변경하지 않습니다. HTML 파일 위치나 브라우저가 바뀌면 저장 데이터가 공유되지 않을 수 있습니다.

**실제 이메일 발송·이메일 인증 서비스·계정 보안·서버 권한 검증·서버 저장·외부 문의 전송·전화 연결은 구현하지 않았습니다.** 체험 계정은 인증 없이 선택할 수 있고 데이터는 브라우저에서 수정할 수 있습니다. 실제 개인정보를 입력하지 마세요. 이번 결과물은 로컬 확인용이며 GitHub push와 배포는 수행하지 않았습니다.
